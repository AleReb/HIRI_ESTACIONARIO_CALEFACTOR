# Descargo de responsabilidad

Este repositorio contiene firmware experimental, diseños electrónicos y
documentación técnica. No constituye un producto terminado, certificado ni
aprobado para seguridad funcional, metrología reglamentaria, uso médico,
protección de personas o control de procesos críticos.

El calefactor puede involucrar temperaturas elevadas, corriente eléctrica,
elementos resistivos y relés. Un error de diseño, montaje, firmware, conexión,
selección de componentes o disipación puede producir sobretemperatura,
incendio, choque eléctrico, daño a sensores, pérdida de datos o lesiones.

Antes de construir o utilizar el sistema, el usuario o integrador debe:

- revisar independientemente esquemáticos, PCB, pistas, aislaciones,
  conectores, polaridades, protecciones y capacidad de corriente;
- instalar fusibles, límites térmicos independientes y medios de desconexión
  adecuados al riesgo;
- verificar la termocupla, el relé y el estado seguro ante fallas;
- validar el equipo en un entorno controlado antes del despliegue;
- realizar calibración y validación metrológica de los sensores;
- cumplir las normas eléctricas, ambientales, de radiofrecuencia, seguridad y
  protección de datos aplicables en el lugar de uso.

Los archivos PCB se entregan como fuentes de diseño y no como archivos de
fabricación aprobados. Deben pasar revisión eléctrica, mecánica, DRC/ERC y de
seguridad antes de generar Gerbers o fabricar.

El software, la documentación y el hardware se proporcionan **tal cual**, sin
garantías expresas ni implícitas de exactitud, seguridad, comerciabilidad,
ausencia de defectos o aptitud para un propósito particular. En la máxima
medida permitida por la ley, Alejandro Rebolledo y los colaboradores no asumen
responsabilidad por daños directos, indirectos, incidentales o consecuentes,
pérdida de datos, lucro cesante, lesiones o daños materiales derivados del uso
o imposibilidad de uso del proyecto.

El usuario es responsable de evaluar si el proyecto es apropiado para su caso
de uso y asume los riesgos de construcción, modificación, operación y
despliegue.
